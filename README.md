# Multilabel RNA Modification Site Prediction Benchmark

A reproducible benchmark for **multilabel classification of RNA modification sites** using a CNN–BiGRU–Attention neural network. The workflow covers dataset construction, five-fold cross-validation, independent test evaluation, and aggregation of performance metrics.

## Prediction task

The model predicts five binary labels in the following order: **m6A**, **m1A**, **Am**, **A-to-I**, and **nonA** (unmodified/negative class). Modification-positive sites may have multiple positive modification labels; `nonA` represents the negative category. Input features are derived from RNA sequences.

## Requirements

- Python **3.10+** (the training script uses `argparse.BooleanOptionalAction`)
- Python packages: `numpy`, `pandas`, `scikit-learn`, `torch`, `gensim`, `openpyxl`
- Bash to run the provided shell scripts

For example, create a Conda environment and install dependencies:

```bash
conda create -n mas-benchmark python=3.10 -y
conda activate mas-benchmark
python -m pip install numpy pandas scikit-learn torch gensim openpyxl
```

Install a PyTorch build appropriate for your hardware if GPU acceleration is desired. Training also runs on CPU (see `--cpu`). Dependency versions are not pinned in this repository.

## Quick start

```bash
# 1. Generate train/test splits and five-fold CV files
unzip ./dataset_genomic_0.8/rmbase_mAs_genomic_cdhit_priority_soft_nr_0.8.zip -d ./dataset_genomic_0.8
bash make_data.sh

# 2. Train, validate, and test CNN–BiGRU–Attention across folds
bash train_test.sh

# 3. Aggregate prediction metrics into an Excel workbook
bash evaluation.sh
```

### 1. Dataset construction

unzip ./dataset_genomic_0.8/rmbase_mAs_genomic_cdhit_priority_soft_nr_0.8.zip -d ./dataset_genomic_0.8

`make_data.sh` runs `split_dataset.py` with these settings:

| Parameter | Value | Meaning |
| --- | --- | --- |
| `--identity` | `0.8` | Identity tag for the CD-HIT-EST-processed dataset |
| `--test_size` | `0.20` | Independent test fraction |
| `--n_splits` | `5` | Number of cross-validation folds |
| `--nona_ratio` | `1.0` | Target ratio of pure nonA to modification-positive sites |
| `--max_sample` | `50000` | Maximum pure-m6A examples in each training dataset |
| `--seed` | `42` | Random seed |

The source TSV is `dataset_genomic_0.8/rmbase_mAs_genomic_cdhit_priority_soft_nr_0.8.tsv`. Splitting groups records by a derived `source_id` to reduce source overlap between development and independent test sets. With `--nona_ratio 1.0`, the intended constructed population has approximately 50% nonA examples, subject to available records. The pure-m6A cap applies to training data, **not** to validation or independent test data; other modification-positive and mixed-label examples are retained according to the script's rules.

Generated files include `train_0.8.csv`, `test_0.8.csv`, label-count summaries, and `cross_val/<fold>/cv_train_<fold>.csv` and `cv_val_<fold>.csv` for folds 1–5. The provided train/test CSVs can be regenerated; CV files must be generated for the default training script.

To change the dataset settings, edit `make_data.sh` or invoke `python split_dataset.py --help`.

### 2. Training and independent testing

`train_test.sh` invokes `classify_cnnbigruattention_ovr.py` with:

- **Architecture:** `CNNBiGRUAttention` (convolutional feature extraction, bidirectional GRU, attention pooling).
- **Encoding:** `OH+W2V1+NUCPROP` (one-hot, 1-mer Word2Vec, and nucleotide-property features).
- **Pretrained embeddings:** files under `word2vec_hg38/`.
- **Training:** 20 epochs, batch size 128, focal binary cross-entropy, seed 42.
- **Validation:** five folds; each trained fold is also evaluated on the independent test set.

```bash
bash train_test.sh
```

Additional options are available via:

```bash
python classify_cnnbigruattention_ovr.py --help
```

Notable options include `--epochs`, `--batch_size`, `--lr`, `--loss {bce,focal_bce}`, `--n_splits`, `--cpu`, `--use_pos_weight` / `--no-use_pos_weight`, and `--use_sampler` / `--no-use_sampler`. The script supports comma-separated encoding experiments and `+`-joined encoding blocks. Keep the encoding name consistent between training and evaluation.

**Output:** `result_g_0.8/CNNBiGRUAttention/OH+W2V1+NUCPROP/` contains per-fold subdirectories (`1/` through `5/`) with prediction CSVs (`val_roc.csv`, `test_roc.csv`), training history, tuned thresholds, and metric summaries, plus aggregate cross-validation CSV summaries in the encoding directory. Thresholds are tuned on validation predictions and then used for the corresponding fold's test predictions.

### 3. Metric aggregation

```bash
bash evaluation.sh
```

`evaluation.py` reads each fold's `val_roc.csv` and `test_roc.csv`, calculates per-label, macro, and micro metrics, and writes mean and sample-standard-deviation summaries across folds to `metrics_CNNBiGRUAttention.xlsx`. The workbook contains sheets named `CNNBiGRUAttention_macro`, `CNNBiGRUAttention_micro`, and `CNNBiGRUAttention_per_label`. Metrics include classification scores and ROC-AUC / precision-recall-based measures where defined.

Run `python evaluation.py --help` for custom prediction paths, encodings, labels, and output names.

## Reproducibility notes

- The default dataset and scripts use the `0.8` identity-tagged input, five folds, and seed `42`.
- The independent test set is reused across the five separately trained fold models; fold-level test scores are **not** five independent test datasets.
- Keep the expected label order (`m6A,m1A,Am,AtoI,nonA`) consistent throughout the workflow.
- GPU availability, installed package versions, and hardware can affect runtime and numerical reproducibility.
- Dataset preparation writes generated CSVs; back up existing outputs before rerunning if you need to preserve them.
